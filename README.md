# Pranav Gunhal — Academic website

Live site: https://pgunhal.github.io/

This repository hosts the static export of the research website. The Next.js source, CV source, and editing instructions are in [pgunhal/devsite](https://github.com/pgunhal/devsite).

The root of `main` is the GitHub Pages publishing directory. `.nojekyll` ensures the generated `_next` assets are served. The prior website is preserved in `old/`.
